# 📈 Share Market Forecasting Application

A machine-learning-based stock market forecasting web application built using Python and Streamlit.

## 🚀 Features

- Live stock market data
- Historical price visualization
- Candlestick charts
- 20-day Simple Moving Average
- 50-day Simple Moving Average
- RSI indicator
- MACD indicator
- Machine-learning price forecasting
- Forecast performance metrics
- Forecast visualization
- CSV download
- GitHub-ready
- Streamlit deployment-ready

## 🛠️ Technologies

- Python
- Streamlit
- Pandas
- NumPy
- Plotly
- Scikit-learn
- yfinance
